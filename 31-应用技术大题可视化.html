⚖️ 三大规则 + 黑洞/奇迹图解

规则1 父子图平衡（10号题47 同源）子图的输入/输出数据流必须与父图对应加工的完全一致（数量与方向），既不能多也不能少
规则2 加工要闭环每个加工既有输入又有输出；只有进没有出=黑洞，只有出没有进=奇迹
规则3 命名规范数据流必须命名（不能同名异物）；外部实体/数据存储不能直连——外部→外部、存储→存储都要经过加工

📋 E-R → 关系模式三规则（题23、24 同源）

联系类型转换方法记忆
1:1并入任一端（加对方主键作外键）随便并
1:n并入 n 端（n 端加 1 端主键作外键）并入多的一方
m:n独立成表：两端主键 + 联系自身属性，主键=两端主键组合多对多必须独立
主键/外键填空主键：能唯一标识且非空；外键：参照另一表主键 FOREIGN KEY ... REFERENCES（12号题27）
弱实体没有自己的主键、依赖宿主实体存在（如"家属"依赖"职工"）：主键=宿主主键+自己的区分属性
SQL 模板建表 CREATE TABLE、约束 PRIMARY KEY / FOREIGN KEY / CHECK；查询 GROUP BY + HAVING（27 号页签有全套）
踩坑m:n 联系的属性（如"成绩"）放在联系表里，不放任何一端实体表

🧩 五类高频算法套路卡

链表类遍历 p = p->next；尾判 p != NULL；插入先接后断 s->next = p->next; p->next = s
二分类循环 lo <= hi；右半 lo = mid+1；左半 hi = mid−1；mid = (lo+hi)/2
排序类双指针分区、temp 交换三行；内层边界 j<n−1−i（冒泡每趟少一个）
字符串类结尾判 s[i] != '\0' 或 i<len；累加器初值 = 0；乘积器初值 = 1
递归类先写出口（if n<=1 return …），再写自调用 f(n−1)+…；DP 用数组打表
矩阵/数组类下标 0 起 vs 1 起看题目；对角/边界元素单独处理

📜 六大设计原则（题41 同源）

开闭原则对扩展开放、对修改关闭——所有模式的共同目标
单一职责一个类只负责一件事
里氏替换子类必须能替换父类（is-a）
依赖倒置依赖抽象接口，不依赖具体实现
接口隔离多个专用接口 > 一个胖接口
迪米特法则只与直接朋友通信，减少耦合
