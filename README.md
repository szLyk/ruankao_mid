# 软考·软件设计师（中级）备考资料

2026 下半年广东考区 · 考试窗口 2026-10-24 ~ 10-27 · 34 天冲刺（9/20 启动）。
考生画像：在职 Java 程序员，会 Java 不会 C，目标一次通过（两科同场连考、均 ≥45/75）。

## 快速上手（每天只开 3 个文件）

1. **`02-每日学习计划表.md`** —— 看今天学什么（34 天逐日排好）
2. **`10~15-讲义题库`** —— 读对应模块的「第一部分 讲义」（基础知识点全在这）
3. **`17-在线练习系统.html`** —— 双击做题：摸底 75 + 六大题库 493 + 网络专项 100 + 应用技术大题 11 + 英语挖空 35（20 篇阅读挖空 + 3 篇真题形态五空完形）+ 网络自测 12 + 考前靶向变式 62，共 **788 项**；考试模式（点选只暂存、📄 交卷才判分出答案，错题重练留池复习（答对不移出，手动「移出」才清））；首次打开先绑定记录文件（黄色条按钮），交卷后自动落盘到 `软考-练习记录.json`，AI 助手可直接读取进度与错题

碎片时间：`18-错题知识点速补.md`（针对摸底 48 错的公式/背诵包）、`19-专业英语-AI阅读20篇.md`（每天 1 篇练语感）。
